Claw: ask for an app and it appearsClaw: pide una app y aparece

Ask in the chat for something you need, such as a mortgage calculator or a weekly plan, and Claw builds a small app on the spot, in the same tab. It remembers what you tell it, sets reminders while the tab is open and keeps your passwords in an encrypted vault.

Pide en el chat lo que necesites, como una calculadora de hipoteca o el plan de la semana, y Claw construye una pequeña app al momento, en la misma pestaña. Recuerda lo que le cuentas, programa recordatorios mientras la pestaña está abierta y guarda tus claves en una bóveda cifrada.

What stays on your machineQué se queda en tu equipo

The model runs on hardware you already have, inside a browser tab. That is what lets the apps be free, with no account and no API key, and it means that what you type, open or say is processed where you are.

El modelo corre en el hardware que ya tienes, dentro de una pestaña del navegador. Eso es lo que permite que las apps sean gratuitas, sin cuenta ni clave de API, y significa que lo que escribes, abres o dices se procesa donde estás tú.

A runtime of our own, written for WebGPUUn motor propio, escrito para WebGPU

The Elffuss engine runs GGUF language models in WebGPU, inside a web page: inference runs in your browser, and the weights are read from a server by HTTP range requests. It is written from scratch as WebGPU shaders, and we check it against llama.cpp layer by layer and token by token. By default, Claw and Code run Liquid AI's LFM3 1.7B on it: the Q8_0 file on a computer and the QAD-Q4_0 file on a phone, where it fits in the browser. With the QAD-Q4_0 file it reads a prompt about 1.3 times faster, and writes about 1.8 times faster, than onnxruntime-web with the recipe Liquid AI recommends, in the same browser.

El motor de Elffuss ejecuta modelos de lenguaje GGUF en WebGPU, dentro de una página web: la inferencia corre en tu navegador y los pesos se leen de un servidor por rangos HTTP. Está escrito desde cero como shaders de WebGPU, y lo comprobamos contra llama.cpp capa a capa y palabra a palabra. Por defecto, Claw y Code ejecutan con él LFM3 1.7B de Liquid AI: el fichero Q8_0 en el ordenador y el QAD-Q4_0 en el móvil, donde cabe en el navegador. Con el QAD-Q4_0 lee el prompt unas 1,3 veces más rápido, y escribe unas 1,8 veces más rápido, que onnxruntime-web con la receta que recomienda Liquid AI, en el mismo navegador.

The same engine also loads Qwen3.5 0.8B and, as advanced options, MiniCPM5 2B and Bonsai 2 27B, Prism ML's 27-billion-parameter ternary model, which comes in a third-party format that llama.cpp does not read. The engine's browser code is published under Apache-2.0.

El mismo motor carga también Qwen3.5 0.8B y, como opciones avanzadas, MiniCPM5 2B y Bonsai 2 27B, el modelo ternario de 27.000 millones de parámetros de Prism ML, que viene en un formato de terceros que llama.cpp no lee. El código del motor para el navegador está publicado con licencia Apache-2.0.

Braid

Version control, like git, for many AI agents changing the same project at once. Each agent works in its own space, and their changes land on main one after another, without git's reject-and-retry loop. Git stays at the edges, so GitHub keeps working.

Control de versiones, como git, para muchos agentes de IA que cambian el mismo proyecto a la vez. Cada agente trabaja en su propio espacio y sus cambios llegan a main uno tras otro, sin el bucle de rechazos y reintentos de git. Git se queda en los bordes, así que GitHub sigue funcionando.

A command-line program in Rust that you build from source with cargo. Version 0.1: keep git as your source of truth.

Un programa de línea de comandos en Rust que se compila desde el código con cargo. Versión 0.1: mantén git como tu fuente de verdad.

Visit BraidVer Braid Source codeCódigo fuente
Hosted service · sign in with GitHubServicio alojado · entras con GitHub

BraidHub

The hosted hub where agents on different machines land their work on the same main. Repositories are private by default, and each can keep a GitHub mirror, so people who use git keep doing so. It also has issues, change requests and public repositories to explore.

El hub alojado donde agentes de distintas máquinas integran su trabajo en la misma rama main. Los repositorios son privados por defecto y cada uno puede tener un espejo en GitHub, así que quien usa git sigue con git. También tiene incidencias, solicitudes de cambio y repositorios públicos para explorar.

We run it, and it stores your repositories. Its protocol is public in the Braid repository.

Lo operamos nosotros y guarda tus repositorios. Su protocolo es público en el repositorio de Braid.
