# Elffuss chat: public copy

This is a copy of the chat at **[elffuss.com](https://elffuss.com/)**, the official site, published here for
networks where elffuss.com is blocked. It is served at https://utopia-ia.github.io/.

On this copy the model's weights come from Hugging Face, and memory and apps are kept in your browser only: they
are not shared with Claw or Code as they are on elffuss.com. Web search is not available here.

Do not edit this repository: every commit is published from the elffuss.com source. `LIVE.json` names the source
commit and `PIN.json` the pinned engine files with their sha256.
