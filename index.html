      Ask anything.Pregunta lo que quieras.

      A model running in this browser writes the answer, on your own device. What you type does not leave it, except a web search you ask for.

      Responde un modelo que corre en este navegador, en tu propio dispositivo. Lo que escribes no sale de él, salvo las búsquedas web que le pidas.

      Meet Elffuss and all its appsConoce Elffuss y todas sus apps

        Runs on this device with the Elffuss engine. Chats are kept in this browser only.Corre en este dispositivo con el motor de Elffuss. Las conversaciones se guardan solo en este navegador.

        This browser cannot run the chatEste navegador no puede ejecutar el chat

        The chat runs a language model on this device's graphics card through WebGPU, and this browser does not offer what it needs. A recent Chrome or Edge on a computer can run it.

        El chat ejecuta un modelo de lenguaje en la tarjeta gráfica de este dispositivo a través de WebGPU, y este navegador no ofrece lo que necesita. Un Chrome o un Edge recientes en un ordenador sí pueden.

        The apps still open hereLas apps se abren igual

        Without WebGPU, Code runs only in a basic mode with no model, and Copilot works with rules only. The speech models of Translator and Copilot fall back to the processor.

        Sin WebGPU, Code solo funciona en un modo básico sin modelo y el Copiloto, solo con reglas. Los modelos de voz de Translator y del Copiloto pasan al procesador.
